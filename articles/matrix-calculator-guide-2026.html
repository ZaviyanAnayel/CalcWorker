Matrix Multiplication

C[i,j] = sum(A[i,k] x B[k,j]) - row times column

Example:

[1 2] x [5 6] = [1x5+2x7, 1x6+2x8] = [19 22]

[3 4]    [7 8]   [3x5+4x7, 3x6+4x8]    [43 50]

Dimension rule: (m x n) times (n x p) = (m x p). Inner dimensions must match. Order matters: AB usually != BA.

Non-commutativity is not a technicality - it changes answers. With A = [[1,2],[3,4]] and B = [[5,6],[7,8]]: AB = [[19,22],[43,50]], but BA = [[23,34],[31,46]]. Completely different matrices. In graphics this means "rotate then translate" lands somewhere different from "translate then rotate" - order of operations is geometric, and swapping factors is a real bug, not a notation quibble.

The identity matrix is the number 1 in matrix form: I = [[1,0],[0,1]], and AI = IA = A for any A. The zero matrix plays 0: A + 0 = A. These exist so matrix algebra keeps the familiar properties - without identities and zeros, solving matrix equations would have no anchor. Whenever a formula needs a "do nothing" matrix, reach for I.

Determinants

2x2: det = ad - bc

Example: det of [4 3; 6 8]... precisely [[4,3],[6,8]]: 4x8 - 3x6 = 32 - 18 = 14.

Meaning: Determinant = area/volume scaling factor of the transformation. det = 0 means the matrix squashes space flat (no inverse exists).

3x3: Expand along a row with cofactors, or use the Rule of Sarrus.

The 3x3 determinant via cofactor expansion is mechanical once laid out. For [[1,2,3],[0,1,4],[5,6,0]]: expand along row one: 1 x (1x0 - 4x6) - 2 x (0x0 - 4x5) + 3 x (0x6 - 1x5) = -24 + 40 - 15 = 1. Nonzero means invertible, and a determinant of 1 means the transformation preserves volume exactly - rotations and shears live here.

Triangular matrices make determinants trivial: just multiply the diagonal. det of [[2,5],[0,3]] = 2 x 3 = 6. Zeros below (or above) the diagonal collapse every cofactor term except the diagonal product. Gaussian elimination exploits this - it triangularizes matrices precisely so determinants become one multiplication.

Inverses and Solving Systems

2x2 inverse: 1/(ad-bc) x [[d, -b], [-c, a]]

Solve: 2x + 3y = 8 and x - y = 1. Matrix form AX = B. A^(-1) = 1/(-5) x [[-1,-3],[-1,2]]... compute: det = 2(-1) - 3(1) = -5. Inverse = (-1/5)[[-1,-3],[-1,2]]. X = A^(-1)B gives x = 2.2, y = 1.2.

(Gaussian elimination is usually faster by hand for larger systems.)

A clean inverse example cements the pattern. A = [[4,7],[2,6]]: det = 24 - 14 = 10, so A^-1 = (1/10)[[6,-7],[-2,4]]. Verify by multiplying back: first row times first column gives (24 - 14)/10 = 1, and the off-diagonals give zero - the identity emerges. Always multiply A x A^-1 after computing; the check takes seconds and catches sign slips.

A zero determinant diagnoses unsolvable systems. The matrix [[1,1],[2,2]] has det = 0, so no inverse exists - and the corresponding system x + y = 3, 2x + 2y = 7 is two parallel lines with no solution. "Singular matrix" is algebra's way of saying "these equations contradict each other." Check the determinant before attempting an inverse.

Where Matrices Appear

  • Computer graphics: Every 3D rotation, scaling, and translation is matrix multiplication (GPUs are matrix engines).
  • Machine learning: Neural networks are stacked matrix multiplications.
  • Economics: Input-output models (Leontief) track industry interdependencies.
  • Quantum mechanics: States and operators are vectors and matrices.

Rotation matrices turn geometry into arithmetic. A 90-degree counterclockwise rotation is [[0,-1],[1,0]]; applied to the point (3,4): (0x3 + -1x4, 1x3 + 0x4) = (-4,3). Every sprite rotation in every video game is this multiplication, executed billions of times per second by the GPU. Matrices are not abstract - they are the frame rate.

Markov chains model anything that hops between states with fixed probabilities. A weather model [[0.7,0.3],[0.4,0.6]] (sunny stays sunny 70% of days) converges under repeated multiplication to a steady-state forecast. Google's PageRank is the same idea at web scale: the ranking vector is the steady state of a giant link-transition matrix.
